# Team Analytics (Lead‑Facing)

## What you’ll see
- A clean team dashboard with quick drill‑down to any user.
- No grading or scoring system—just clear activity data and trends.

## Main sections
1) **Team Summary Cards**
   - Total Transactions (team)
   - Total Quantity Moved
   - Unique Parts Handled
   - Active Days

2) **Team Trends**
   - Daily/weekly activity chart for the selected date range.

3) **User List**
   - Sortable list of users with the same summary metrics.
   - Click a user to open their personal analytics view.

4) **User Detail (drill‑down)**
   - Same layout as “My Analytics,” scoped to that user.

5) **Glossary**
   - Short explanations for each metric.

## Fairness rules
- **Advanced Inventory** and **Advanced Remove** are labeled but treated the same as single entries/removals.
- Bulk work is visible and counted the same way as any other work.

## Why this is better
- Fast review of team activity.
- Easy drill‑down without opening extra windows.
- Clear data with zero “grading” confusion.

## Delivery Format
- Rendered as HTML in WebView2, using the same approach as ReceivingAnalytics_Enhanced.html.
- Includes a print‑friendly layout for letter‑size paper.
