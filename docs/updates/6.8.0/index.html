Highlights

What is new in 6.8.0

One Analytics window for you and your team

Analytics in the View menu now opens a single workspace with Myself and Team views. Supervisors, leads, and developers see the team view; everyone sees their own activity. The separate WIP user analytics window has been retired.

Receiving Analytics keeps up with you

Changing any filter now reloads the page data and applies your filters again, so a stale list is never left on screen. A purchase order line counts as partial only while it is above zero and below 90% received.

Suggestion boxes stop second-guessing you

Part, user, location, warehouse, operation, and order fields backed by Infor Visual no longer reject a value that is missing from the lookup list. Those lists are cached for ten minutes, so typing stays responsive and the Visual server is asked less often.

What changed

Details of this release

Analytics with Myself and Team views

Analytics opens one workspace built around who you are. The Myself view shows your own transactions and quantities. The Team view is offered to supervisors, leads, and developers and shows everyone's activity in the same layout.

The old role check now happens once, when the workspace opens, so a person who is not allowed to see team figures is never shown a team figure that is empty by mistake.

Trends, recent activity, and team drill-down

A Trends & Context chart shows Transactions or Quantity over time, grouped Daily or Weekly. A Recent Activity list shows the latest transactions, and Team Drill-Down expands one person to review their activity.

A Glossary section explains every figure on the page, so two people reading the same screen agree on what it means.

Export and print straight from Analytics

Export Summary writes the headline figures, Export Activity writes the detailed transaction list, and Print prints the page as it appears. Refresh View reloads the numbers without closing the window.

Receiving Analytics filters reload the data

Every filter change on the Receiving Analytics page now reloads the page data and then applies your filters again. Previously a filter could be applied to a list that had already moved on, which made a line look missing or out of date.

Status filters (Show Late, Show Partial, Show On Time, Show Open, Show Closed), text filters, and part-type filters all behave the same way.

Partial means under 90% received

A purchase order line is treated as partial only when it is more than zero and less than 90% received. At 90% or higher the line is treated as complete. Clearing Show Partial removes exactly those lines and leaves everything else alone.

Receive dates follow a clear order

The page now decides which date to show in a fixed order: line desired date, line promise date, PO desired date, PO promise date, and finally the order date. Rows with no receive date type are highlighted in red so they are easy to spot and correct.

Infor Visual fields accept values outside the list

Fields that draw their suggestions from Infor Visual no longer show a "not valid" warning or clear what you typed when the value is missing from the lookup list. The typed value is kept as entered, which matters when the list has not caught up with the Visual database.

Fewer Visual lookups while you type

Infor Visual suggestion lists are cached for ten minutes, and overlapping requests for the same list now wait for one lookup instead of starting several. The result is a responsive suggestion box and less load on the Visual server during busy periods.

Visual queries time out and recover

Queries against Infor Visual now carry a timeout and can be cancelled, so a slow server no longer leaves a screen waiting with no way out. Connection pooling and disconnect recovery were repaired, which means a dropped connection recovers without restarting the application.

Updated help for analytics

The in-app help gained a User and Team Analytics article covering activity totals, the trend chart, and the drill-down views. It is available from the Help menu and from the help button on the analytics window.

Why it matters

What this means on the floor

Answers without asking for a report

Leads and supervisors can open Analytics and see how their team is doing, print the page for a stand-up, or export the detail to Excel. Everyone reads the same definitions in the same place.

Receiving numbers you can act on

Because every filter change reloads the data, a line that is late or partial is shown as it stands right now, not as it stood when the page was opened.

Less waiting on Infor Visual

Free text is accepted where the list is incomplete, repeated lookups reuse a cached result, and a slow or dropped Visual connection no longer stops the whole screen.

What you need to do

Nothing to set up

No action is required after this update.

  • Analytics is available from the View menu. The team view follows the permissions your account already has.
  • Receiving Analytics and the suggestion boxes use the settings you already have; nothing needs to be turned on.
  • Existing inventory, transactions, quick buttons, themes, and preferences carry over unchanged.

Need help?

Reporting a problem

If a chart in Analytics does not match what you expect, a line is missing from Receiving Analytics, a value is rejected that Infor Visual clearly has, or a Visual screen stops responding, contact your supervisor or the MTM IT support team and include the version number shown at the top of this page.
